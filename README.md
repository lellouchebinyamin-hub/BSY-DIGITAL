# B.S.Y DIGITAL

Site vitrine du studio B.S.Y DIGITAL (hébreu RTL + anglais, mode sombre/clair).

- `index.html` : tout le site (HTML, CSS, JS dans un seul fichier)
- `logo-mark.png`, `logo-mark-light.png` : logo (sombre / clair)
- `work/` : captures desktop et mobile des projets

À remplacer avant la mise en ligne : WhatsApp, téléphone et e-mail (objet `CONTACT`), avis clients d'exemple, lien Google « laisser un avis ».
Le formulaire de contact enregistre les demandes seulement dans la version Claude ; ailleurs il passe par WhatsApp tant qu'aucun backend n'est branché.
